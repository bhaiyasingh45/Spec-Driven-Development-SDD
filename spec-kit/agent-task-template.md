# Agent Task Template

## Task ID

`TASK-XXX`

## Objective

State the smallest independently verifiable outcome the coding agent must deliver.

## Requirement References

- `REQ-XXX`
- `AC-XXX`

## Context

Provide the relevant specification, architecture, files, interfaces, or constraints the agent must understand before acting.

## Expected Changes

Describe the expected behavior or implementation boundary without adding requirements that are not present in the specification.

## Validation

Define the test or verification evidence required to mark the task complete.

## Agent Completion Report

The agent should report:

- What changed
- Requirements satisfied
- Tests/checks executed
- Any assumptions made
- Any remaining issues or follow-up tasks
