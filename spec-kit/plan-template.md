# Implementation Plan Template

## Objective

Summarize what will be implemented and why.

## Architecture

Describe the components, services, modules, and boundaries involved.

## Data Flow

Describe how data moves through the system for the feature.

## Technical Decisions

Document important design choices and alternatives considered.

## Dependencies

List APIs, libraries, services, schemas, or other prerequisites.

## Risks

Identify technical, operational, security, and performance risks.

## Validation Strategy

Define tests, checks, and acceptance validation needed before implementation is complete.
