# Project Constitution

## Purpose
Define the principles that every feature and implementation in this repository should follow.

## Principles

1. **Specification first** — requirements and acceptance criteria are documented before implementation.
2. **Traceability** — implementation tasks should be traceable back to a requirement.
3. **Testability** — every functional requirement should have verifiable acceptance criteria.
4. **Simplicity** — prefer the smallest design that satisfies the specification.
5. **Documentation** — important architectural and product decisions should be recorded.

## Change Rule
When a requirement changes, update the specification first and then reconcile the implementation with the updated specification.
